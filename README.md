# чо?

Ленивый объяснятор простым русским языком. Разжёвывает код, ошибки, термины, статьи и
системы: сначала суть, потом одна аналогия и оговорка, когда это не работает.

```text
> /cho мьютекс

Мьютекс — щеколда на общие данные. Как туалет в поезде: один зашёл и заперся,
остальные курят у двери. Без щеколды два потока хватают одно и то же разом, и данные
идут по пизде. Но: забыл отпереть — все висят нахуй вечно.
```

## Ручки

**Простота** от 1 до 5. Чем выше, тем проще. По умолчанию — 3.

| Уровень | Название | Как объясняет |
|---------|----------|---------------|
| 1 | По делу | Простым языком, со всеми важными деталями |
| 2 | Без терминов | Без профессиональных слов, с одной бытовой аналогией |
| 3 | На пальцах | Для школьника, с примером из жизни |
| 4 | Как бабушке | Для человека совсем не из IT |
| 5 | В двух словах | Одна-две фразы |

**Мат.** По умолчанию — high.

| Режим | Как звучит |
|-------|------------|
| off | Без мата, простым языком |
| low | Мат только в оценках: «заебись», «пиздец» |
| high | Мат там, где его сказал бы живой человек. Изредка — восклицание вроде «ебать-колотить» или рифма вроде «деплой-хуеплой» |

## Установка

**Claude Code**

```bash
claude plugin marketplace add golyshevskii/cho
claude plugin install cho@cho
```

**Codex**

```bash
codex plugin marketplace add golyshevskii/cho
codex plugin add cho@cho
```

**Gemini CLI**

```bash
gemini extensions install https://github.com/golyshevskii/cho
```

**Только скилл**

```bash
npx skills add golyshevskii/cho
```

## Как пользоваться

```text
/cho <код, ошибка или термин>
/cho 4 Kubernetes
/cho 5 high что такое монада
/cho off 2 OAuth
чо бля? <вставить стектрейс>
```

Не дошло — напиши **«чо?»**: объяснение станет на уровень проще. Хочешь глубже —
напиши **«подробнее»**. Режим держится до фразы **«нормальный режим»**.

В Claude Code команда — `/cho:cho`, при установке только скилла — `/cho`.

## Где мата не будет

- В коде, коммитах, PR и документации.
- В предупреждениях о безопасности и необратимых операциях (`DROP TABLE`, `rm -rf`).
- В пошаговых инструкциях, где ошибка в порядке шагов ломает данные.

Мат направлен на баги, легаси и кривую доку. На пользователя — никогда.
Перед объяснением скилл читает присланный файл или ошибку. Если контекста не хватает,
он задаёт один вопрос. При упрощении важные условия сохраняются.
